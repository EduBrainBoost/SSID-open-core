Public OpenCore module: Synthetic/open-data pipeline examples and public schemas.

## Scope

This module contains **public-facing** content only:
- Public API interfaces
- Reference implementations (mock backends)
- Synthetic test data
- Public documentation

## Not Included

- Private source code copies
- Production credentials or secrets
- Customer/user PII
- Internal infrastructure details
- Internal agent runtime internals
